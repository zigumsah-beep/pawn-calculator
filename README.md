# คำนวณดอกเบี้ยขายฝาก

โปรแกรมคำนวณวันและดอกเบี้ยขายฝาก (ไฟล์เดียว `index.html` ไม่ต้องติดตั้งอะไร)

## ฟีเจอร์
- นับจำนวนวันตั้งแต่วันที่รับฝากถึงวันที่ไถ่ถอน
- ดอกเบี้ย 2% สำหรับยอดไม่เกิน 100,000 บาท (เลือก 1.25% เองได้) และ 1.25% อัตโนมัติเมื่อยอดเกิน 100,000
- เศษวันเกิน 15 วัน คิดเต็มเดือน (ไม่เกินคิดครึ่งเดือน ปรับได้)
- ส่วนลดดอกเบี้ย 10% เมื่อยอดเกิน 10,000 แต่ไม่ถึง 100,000 บาท และระยะเวลาเกิน 15 วัน
- แยกโหมด ไถ่ถอน และ ต่อดอก (ต่อดอกคิดเฉพาะดอกเบี้ยถึงวันครบกำหนด)
- รองรับมือถือ และโหมดมืด

## วิธีใช้
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย

## เผยแพร่ด้วย GitHub Pages
1. Settings > Pages
2. Source: Deploy from a branch > เลือก `main` และโฟลเดอร์ `/ (root)`
3. รอสักครู่ จะได้ลิงก์ `https://<username>.github.io/<repo>/`
